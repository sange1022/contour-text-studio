# 轮廓文字

纯图片版轮廓文字视觉生成器，使用 React + Vite 构建。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 已实现

- 1—5 张图片导入与序列选择，初始画布不使用任何预设轮廓
- 基于上传图片像素的明暗阈值、连通区域过滤及内外轮廓识别
- 原图可直接铺满画布作为海报背景，并可随时关闭
- 画布与 PNG / SVG 导出自动使用当前图片的原始宽高
- 原图、1:1、3:4、4:5、9:16、16:9 常用画布尺寸预选
- 轮廓、圆化、粒子、网格、回吸五种静态海报样式
- 阈值、平滑度、最小面积与海报样式控件
- 自定义轮廓文字，支持方形、圆形、三角形底块与空心样式
- PNG / SVG 静态图片导出
- 白底黑线、钴蓝强调的精简海报编辑界面与移动端折叠布局
- 专注静态图片海报工作流
